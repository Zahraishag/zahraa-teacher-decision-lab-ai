# ZAHRAA™ Teacher Decision Lab

نسخة واجهة أولية لمختبر زهراء للقرار التربوي.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح.
3. اضغط «ابدأ تحليل موقف تعليمي».
4. استخدم «المثال التجريبي» لتعبئة الحقول سريعًا.

## ما يعمل الآن
- أربع شاشات أساسية.
- حفظ السياق محليًا.
- إنشاء معرف مستقل للجلسة.
- سؤال تكيفي تجريبي.
- عرض البدائل.
- حاجز يمنع إنشاء الخطة قبل موافقة المعلم.

## المرحلة التالية
ربط الواجهة بـ Gemini API من خلال خادم آمن، وعدم وضع مفتاح API داخل ملفات المتصفح.
