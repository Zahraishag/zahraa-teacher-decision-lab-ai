# Demo Guide for Judges

## Fast path (under 2 minutes)

1. Open the live demo.
2. Review the homepage decision diagram.
3. Scroll to the DataHub metadata and lineage section.
4. Click **ابدأ رحلة اتخاذ القرار**.
5. Review the three alternatives.
6. Open the analysis for one alternative.
7. Click **اعتماد هذا البديل**.
8. Complete the four teacher confirmations.
9. Click **اعتماد القرار**.
10. Generate the plan.
11. Review Plan Provenance and the final Decision Trace.

## Suggested validation

Run the journey three times, selecting a different alternative each time. The decision title and implementation-plan content should change accordingly.

## Prototype transparency

The interface demonstrates the intended metadata-driven and DataHub-powered reasoning workflow. It is not presented as a live production DataHub connection.
